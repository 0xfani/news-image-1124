One front page for Tuesday 24 November 2026: 52 stories first reported that day, across every continent, in a single 1024x1024 picture (`entry.png`). The page carries a dated masthead, lead stories with pictograms, a grid of smaller cards and an "also on this day" list. `main.py` checks that the picture is a whole PNG within the bounty's limits and copies its bytes unchanged to `/output/entry.png`, so both runs write the same file.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
